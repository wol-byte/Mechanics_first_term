[Русский](#лабораторные-работы-по-физическому-практикуму-"Механика"-2026 года-(осенний-семестр))
## Description
This project is an archive of laboratory work completed over the course of the semester, implemented using modern computer technologies (Python, Jupyter, LaTeX, etc.).
## Navigation
The laboratory works are divided into folders. One folder corresponds to one work. Inside, you will find the Jupyter source code in the ipynb format, the protocol source code in the tex format, and the compiled protocol in PDF format.
